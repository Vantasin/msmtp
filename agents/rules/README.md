# Rules

This directory contains durable repository constraints and operating standards.

Files:

- [`repo-rules.md`](./repo-rules.md): repository-level expectations and
  precedence
- [`documentation-rules.md`](./documentation-rules.md): how and when
  documentation should be updated
- [`change-management-rules.md`](./change-management-rules.md): changelog and
  drift-review expectations
- [`safety-rules.md`](./safety-rules.md): safety boundaries for credentials,
  config, and automation
