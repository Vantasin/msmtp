# Update Docs

1. Decide whether the change belongs in [README.md](../../README.md),
   [`docs/README.md`](../../docs/README.md), [`agents/`](../), local directory
   `README.md` files, or several of them.
2. Keep the root [README.md](../../README.md) high-level and human-first.
3. Put durable agent policy in [`agents/rules/`](../rules/).
4. Put explanatory background in [`agents/context/`](../context/).
5. Put repeatable procedures in [`agents/workflows/`](./).
6. Keep human docs and canonical agent guidance consistent.
