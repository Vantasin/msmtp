# Update Docs

1. Decide whether the change belongs in `README.md`, `docs/`, `agents/`, local
   directory `README.md` files, or several of them.
2. Keep the root `README.md` high-level and human-first.
3. Put durable agent policy in `agents/rules/`.
4. Put explanatory background in `agents/context/`.
5. Put repeatable procedures in `agents/workflows/`.
6. Keep human docs and canonical agent guidance consistent.
