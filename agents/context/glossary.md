# Glossary

- `thin wrapper`: a minimal platform-facing file that routes into canonical
  repository guidance
- `canonical`: the authoritative source of truth
- `drift review`: a review that checks whether instructions and documentation
  still match the actual repository state
- `atomic replacement`: writing a new file or symlink to a temporary path in
  the destination directory and then renaming it into place
- `directory README`: a local file that explains a subdirectory's purpose
- `msmtp`: a lightweight SMTP client often used as a sendmail replacement
