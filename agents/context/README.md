# Context

This directory contains durable background knowledge that helps agents reason
correctly about the repository.

Files:

- [`project-overview.md`](./project-overview.md): what the repository is for
- [`architecture-context.md`](./architecture-context.md): structure and
  operating boundaries
- [`domain-context.md`](./domain-context.md): `msmtp` domain background
- [`current-state.md`](./current-state.md): accurate snapshot of current repo
  maturity
- [`glossary.md`](./glossary.md): shared terms used across the docs
